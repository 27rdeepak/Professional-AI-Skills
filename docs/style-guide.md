# Style Guide

- Use direct professional language and imperative instructions.
- Use lowercase hyphen-case skill folders and one matching H1.
- Keep `SKILL.md` under 500 lines; move detail to direct `references/` children.
- Frontmatter contains exactly `name` and `description`.
- Put capability and all triggers in the description.
- Quote strings in `agents/openai.yaml`; its prompt must mention `$skill-name`.
- Distinguish facts, assumptions, inference, and recommendation.
- Preserve units, periods, baselines, and caveats.
- Specify observable analysis artifacts, never hidden chain of thought.
- Make irreversible or externally consequential actions explicit.
- Use relative links and tables only for real comparisons.
